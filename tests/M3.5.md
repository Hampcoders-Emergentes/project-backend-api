## Identidades y flujos reales

- IAM: AuthenticationController sign-up y sign-in → UserCommandService, BCrypt HashingService, UserRepository, UnitOfWork y TokenService reales. La consulta de usuario de cada request usa UserQueryService/EF. No se generan JWT manualmente ni se simulan identidades autenticadas.
- Profiles: UserRegisteredEventHandler crea Profile mediante ProfileCommandService real. Completar homeowner por HTTP usa el UserId del JWT, ProfileRepository/uniqueness checker reales y genera HomeownerId. GetProfileClaims/IsHomeownerActive de ProfilesContextFacade/QueryService consultan PostgreSQL.
- Assets: el handler real ProfileCompleted crea PropertyPortfolio; se comprueba que exista para no ocultar un fallo capturado por ese handler. PropertyCommandService y PropertyPortfolioCommandService crean propiedad sintética y entrada de portafolio. IoTDeviceCommandService registra, asigna y registra instalación lógica; repositorios/UoW reales.
- Nuevo recorrido: servicios/controladores de StoreManagement y AlertManagement, adaptador ExistingAssetsDeviceLinkAuthority, repositorios/contexto EF y detector puro reales.

UserId `us-…`, ProfileId `prof-…`, sujeto propietario `ho-…`, PropertyId e ID interno `dev-…` se obtienen de resultados persistidos y contratos. Se verifican sus diferencias; no se convierten por parecido. Serial Edge sintético distinto del ID interno, cotejado por la autoridad real. StoreId no reemplaza PropertyId. El registro público usa el rol User existente, no eleva a Admin ni introduce Manager/roles nuevos.

**Preparación técnica, no prueba HTTP:** propiedad/portafolio/dispositivo se preparan llamando servicios reales de aplicación en scope, no controladores de Assets. RecordDeviceInstallationCommand recibe una referencia TechnicianId sintética opaca admitida por el contrato actual. No se valida una cuenta de técnico/operador, autorización HTTP de instalación ni instalación física. Se inspeccionaron las rutas heredadas de registro/asignación/instalación y sus comandos; sus garantías de autorización no quedan acreditadas por este ensayo.
